# 06: 任务 tab 列表 UI

**What to build:** 侧边栏出现"任务" tab(与房间/角色并列);任务房从房间列表分流到任务列表,每行显示状态灯(空闲/进行中/出错,直通映射成员状态)+ 任务名 + 项目名(路径尾段)+ 最后动态时间,按最近活跃倒序;点击进入复用现有 RoomView(消息流/trace/输入框全同)。开 3 个任务,扫一眼任务 tab 即知谁在干活。

技术要点:三态 = 单成员任务房成员状态的直通映射(thinking/streaming→进行中;error→出错;其余→空闲),零推导零持久化;多成员任务房取成员状态聚合(任一进行中即进行中,全 error 才出错)。i18n zh/en。

**Blocked by:** 03(任务房 schema——有 kind 才有列表筛选依据)
