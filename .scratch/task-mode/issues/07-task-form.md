# 07: 任务建房表单

**What to build:** 用户在任务 tab 点"新建任务",弹出**任务专属简表单**——任务名 + 项目路径(必填,目录选择)+ 角色(下拉,含"工程师"默认模板一键填充 persona)+ 权限档(默认 full,明示"完全权限"代价)——填完即建出 kind:'task' 房间(经 03 的路由校验)。表单不出现任何聊天概念字段(chainBudget/mode/订阅/上下文模式)。

"工程师"模板:内置 persona 文本(任务行为契约的默认版),填充后用户可改。

**Blocked by:** 06(表单挂在任务 tab 内;亦依赖 03 的校验路由,由 06 传递)

**Status:** ready-for-agent

- [ ] 任务 tab 有新建入口,表单仅四要素(名/路径/角色/权限),无聊天字段
- [ ] 项目路径必填校验:空/本机不存在 → 表单内报错不发请求
- [ ] 角色下拉含"工程师"模板,选中预填 persona,可编辑
- [ ] 权限档默认 full,选项文案明示各档真实能力(full 含命令与网络)
- [ ] 提交成功 → 跳转新任务房消息视图
- [ ] zh/en 文案齐
- [ ] typecheck 绿
